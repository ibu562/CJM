# Persona Map · Персоны и путь ученика

Внутренний сайт школы «Архитектор смыслов»: карта 5 персон, досье, CJM на 13 этапов,
пересечения (кривые эмоций, матрица «персона × этап», общее ядро болей).
Выбранная архитектура: **Вариант 2** — статический сайт для GitHub Pages,
данные в CSV (позже — Google-таблица).

## Структура

| Файл | Что это |
|---|---|
| `index.html` + `style.css` + `app.js` | сайт (vanilla JS, без зависимостей, hash-роутер: `#/`, `#/persona/P1`, `#/cjm/P1`, `#/compare`) |
| `data.js` | сгенерированные данные — **не редактировать руками** |
| `data/personas.csv` | 5 персон × 23 поля (профили) — канон, будущая вкладка Google-таблицы |
| `data/stages.csv` | 13 этапов: зона, макрофаза, цель бизнеса |
| `data/cjm.csv` | 65 ячеек карт: персона × этап × секции (цель, действие, боли, эмоция ±2 и термин Плутчика, A-HA, данные, голос, TO-BE) |
| `data/matrix.csv` | матрица разрывов: статус (red/orange/yellow/green/gray) + текст; persona_id=ALL — общий вывод этапа; persona_id=EXPL — колонка «Пояснения» (заполняется построчно по мере разбора с Ириной; сделан этап 1) |
| `tools/import_from_xlsx.py` | одноразовый импорт из `Deliverables/CJM_матрица_решений_встреча.xlsx` (статусы берёт из заливки ячеек) |
| `tools/build_data.py` | сборка `data.js` из CSV — запускать после каждой правки CSV |

## Как обновлять данные

1. Правишь `data/*.csv` (Excel/LibreOffice, кодировка UTF-8 с BOM сохраняется).
2. `python persona-map/tools/build_data.py`
3. Обновить страницу. Для публикации — закоммитить и запушить (после настройки GitHub Pages).

Локальный просмотр: `python -m http.server 8137 --directory persona-map` → http://localhost:8137
(или через preview-конфигурацию `persona-map` в `.claude/launch.json`).
